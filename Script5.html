Image satellitaire de Saint-Joseph

tot <- get_apicarto_cadastre("97224", type = "commune")
st_write(tot, "projet.gpkg", "commune", delete_layer = T)
## Deleting layer `commune' using driver `GPKG'
## Writing layer `commune' to data source `projet.gpkg' using driver `GPKG'

r <- get_wms_raster(tot,
               layer = "ORTHOIMAGERY.ORTHOPHOTOS",
               res = 10,
               crs = 5490,
               rgb = TRUE,
               filename = "SaintJoseph.tif",
               overwrite = FALSE,
               verbose = TRUE)
r <- rast("SaintJoseph.tif")
plot(r)

Cette carte est une image satellitaire de la commune de Saint-Joseph. On remarque que certaines zones ne sont pas occupées ou très peu urbanisées. Cela peut s’expliquer par les contraintes liées au relief, notamment dans les zones les plus escarpées. Les espaces habités semblent donc se concentrer dans les zones plus accessibles. Le relief joue ainsi un rôle dans la répartition de la population à l’intérieur de la commune. Ces contraintes peuvent également avoir un impact sur les inégalités sociales : les zones plus isolées disposent parfois de moins d’équipements, de services ou d’opportunités économiques, ce qui peut renforcer certaines situations de pauvreté

Cette image satellitaire se concentre sur les carreaux habités de Saint-Joseph. Malgré le fait que Saint-Joseph soit la 6e commune la plus peuplée de Martinique, on observe un territoire très marqué par le relief et la végétation, avec de nombreuses zones surélevées et boisées. Cela montre que le territoire est difficile à aménager de manière homogène. Certaines zones apparaissent plus isolées ou moins accessibles, ce qui peut influencer l’installation des habitants et l’organisation des activités.

Les recettes des communes de Martinique

data <- read.csv2("ofgl-base-communes.csv", dec = ".")
data <- data[,c(15,28)]
names(data) <- c("Code", "Montant")
st_layers("cadastre-972-communes.geojson")
## Driver: GeoJSON 
## Available layers:
##              layer_name geometry_type features fields crs_name
## 1 cadastre-972-communes Multi Polygon       34      4   WGS 84
Mart <- st_read("cadastre-972-communes.geojson", quiet=T)
Mart <- Mart[,1]
Mart$id <- as.numeric(Mart$id)
inter <- merge(data, Mart, by.x = "Code", by.y = "id")
st_write(inter [,c(1:3)],"jointure.gpkg", "inter", delete_layer = T, quiet = T)
jointure <- st_read("jointure.gpkg")
## Reading layer `inter' from data source 
##   `C:\Users\I J\Documents\Iudig\Licence\L3S6\SIG\iudig.github.io\jointure.gpkg' 
##   using driver `GPKG'
## Simple feature collection with 34 features and 2 fields
## Geometry type: MULTIPOLYGON
## Dimension:     XY
## Bounding box:  xmin: -61.22909 ymin: 14.3887 xmax: -60.8096 ymax: 14.87873
## Geodetic CRS:  WGS 84
mf_map(jointure, type = "choro", var = "Montant", border = NA)

Cette carte représente le montant des recettes par habitant dans les différentes communes de Martinique.Les couleurs foncées correspondent aux communes ayant les recettes les plus élevées, tandis que les couleurs plus claires représentent les communes disposant de recettes plus faibles.On observe que les situations sont très contrastées selon les communes. Certaines disposent de ressources financières plus importantes, alors que d’autres semblent avoir davantage de difficultés financières. Saint-Joseph apparaît parmi les communes ayant des recettes par habitant relativement faibles.Ces différences peuvent avoir un impact sur les capacités d’aménagement et les services proposés aux habitants. Une commune disposant de moins de ressources peut rencontrer plus de difficultés pour développer les infrastructures, les transports ou certains équipements publics.Cette carte complète donc l’analyse des inégalités territoriales en montrant que les écarts ne concernent pas seulement les habitants, mais aussi les moyens financiers des communes elles-mêmes.
